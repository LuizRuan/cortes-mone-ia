# Fluxo de colaboração

- Trabalhar e publicar exclusivamente na branch `Ruan`.
- Não enviar commits diretamente à `main` nem realizar merges; o usuário revisa pelo pull request.
- Preservar `.env`, vídeos, resultados e dados locais fora do Git.
- Para alterações no Studio, validar `npm --prefix frontend run build` e os testes Python pertinentes.
- Distinguir validação com IA simulada de avaliação real com Groq e vídeos de usuários.
